# Data handling note

The public repository copy of `Data/Source/customers.csv` intentionally omits the `Email` and `Phone` columns. The source data supplied to the project included those fields, but they are not required for the public code sample or the dimensional analytics demonstrated here. The original private working copy is not changed by this repository preparation.

Before publishing, review the Power BI file and any screenshots for embedded personal or confidential information. Do not commit credentials, passwords, `.env` files, private connection strings, or production customer information.
